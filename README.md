# GCP Static Portfolio Website

## Overview

This project demonstrates how to host a static website using Google Cloud Platform (GCP) Cloud Storage.

The goal was to create a low-cost, highly available website without using virtual machines or traditional web hosting services.

## Technologies Used

- Google Cloud Platform (GCP)
- Cloud Storage
- HTML
- CSS
- Google Cloud Console

## Project Objectives

- Create a Cloud Storage bucket
- Configure static website hosting
- Upload website files
- Configure public access
- Validate external website access

## Architecture

User → Internet → Google Cloud Storage Bucket → Static Website

## Implementation Steps

1. Created a Cloud Storage bucket.
2. Enabled static website hosting.
3. Uploaded website files (HTML/CSS).
4. Configured bucket permissions for public access.
5. Tested website accessibility through the provided URL.

## Skills Demonstrated

- Cloud Storage Administration
- Static Website Hosting
- Cloud Resource Configuration
- Access Control and Permissions
- Cloud Infrastructure Fundamentals

## Results

Successfully deployed and hosted a static website using Google Cloud Storage.

Users were able to access the site through a public URL without requiring a virtual machine or web server.

## Lessons Learned

- How static website hosting works in cloud environments
- Differences between object storage and virtual machine hosting
- Basic cloud security and permission management
- Cost-effective methods for hosting web content
